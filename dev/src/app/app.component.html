About ng-luna

ng-luna is an Angular component library that provides retro Windows-styled UI components.

Features

  • Standalone Angular components
  • Retro Windows aesthetic
  • Accessible with ARIA support
  • Keyboard navigation
  • IBM Plex font family

Available Components

  • Button
  • Checkbox
  • Fieldset
  • Input
  • Modal (LunaModalService)
